# Multi-Modal Counter-UAS Trajectory Estimation (IMM-EKF)

An end-to-end Python implementation of an Interacting Multiple Model Extended Kalman Filter (IMM-EKF) designed for real-time, 3D threat trajectory estimation of Class 1/2 small Uncrewed Aerial Systems (sUAS). 

This repository serves as the functional codebase for the manuscript: *Dynamic State Estimation and Threat Trajectory Prediction for Low-RCS Counter-UAS via Interacting Multiple Model EKF and Decision-Level EO/IR Sensor Fusion*.

## System Architecture
Modern Counter-UAS platforms suffer from optical track loss during evasive maneuvers and visual occlusions. This tracking engine solves this by fusing 4K RGB and Thermal IR bounding centroids with active range telemetry into a deterministic kinematic framework.

* **Coordinate Engine:** Transforms WGS-84/ECEF data into a Local Tangent Plane (NED) Cartesian frame to eliminate spherical distortion over tactical engagement zones.
* **Clutter Rejection:** Implements a Mahalanobis Distance Validation Gate (99% confidence interval) prior to Hungarian data association to filter background optical clutter.
* **IMM-EKF Core:** Runs parallel Constant Velocity (CV) and Coordinated Turn (CT) kinematic models, utilizing dynamic Markov mode probabilities to track high-g evasive banking maneuvers.

## Operational Performance (LRDDv3 Benchmark)
The filter was evaluated against synchronized multi-modal telemetry, including a forced 3-second total optical blackout and aggressive lateral maneuvers.

| Metric | Single CV EKF | Proposed IMM-EKF | Operational Advantage |
| :--- | :--- | :--- | :--- |
| **3D Position RMSE** | 10.198 m | **1.220 m** | 88% reduction in tracking error. |
| **Velocity RMSE** | 7.773 m/s | **1.377 m/s** | High-precision vectoring for kinetic effectors. |
| **Occlusion Recovery** | 33.391 m | **4.118 m** | Dead-reckons trajectory during a 3-second NLOS window. |
| **Math Latency** | 0.110 ms | **0.354 ms** | Imposes zero bottleneck on visual edge processing (29.7 FPS). |

## Quickstart (Google Colab)
The core simulation, complete with synthetic sensor noise injection and plotting, is fully contained within a Google Colab notebook for immediate execution.

1. Open `notebooks/trajectory_analysis.ipynb` in Google Colab.
2. Run **Cell 1** to initialize the `ThreatTracker_IMMEKF` class.
3. Run **Cell 2** to generate the synthetic evasive flight path.
4. Run **Cell 3** to execute the filtering loop and generate the 3D trajectory and Markov probability visualizations.
